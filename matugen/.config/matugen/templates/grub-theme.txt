# Formato "GRUB theme" (gfxmenu), ver
# https://www.gnu.org/software/grub/manual/grub/html_node/Theme-file-format.html
# (tambien local: `info grub`, nodo "Theme file format" -- fuente de
# verdad usada para groundear cada propiedad de este archivo). Cada
# construccion nueva ademas quedo verificada contra un ejemplo REAL que
# ya funciona en esta misma maquina antes de usarla aca: menu_pixmap_style
# y @KEYMAP_MIDDLE@ -> /usr/share/grub/themes/starfield/theme.txt (theme
# stock que trae el paquete grub); +image con left/top/file y el label de
# countdown con id="__timeout__" -> temas de GRUB publicados que lo usan.
# "item_pixmap_style" (divisor por fila no seleccionada) SE SACO a
# proposito: es la unica propiedad que no aparecio en ningun ejemplo real
# de los consultados, y es la sospechosa mas probable de haber roto el
# parseo completo del theme (GRUB no tira ningun error visible si
# theme.txt no carga -- simplemente cae al menu de texto plano, que fue
# justo lo que paso al probarlo).
#
# El fondo, avatar (~/.face en circulo), glow del avatar, tarjeta de 9
# slices del menu y "pill" de seleccion los genera
# hypr/.config/hypr/scripts/generate-grub-assets.sh (post_hook de este
# mismo template, ver matugen/.config/matugen/config.toml) con
# ImageMagick. __HOSTNAME__ lo resuelve ese mismo script al final (sed),
# matugen no tiene esa variable. Las fuentes (font.pf2/font-bold.pf2,
# Plus Jakarta Sans Regular 16 / SemiBold 28 -- fuente de interfaz del
# design system, decision D1 / P1.3) son
# estaticas, viven en grub/theme/ (no dependen de colores, no las genera
# matugen) y grub-mkconfig las carga solo por estar en la carpeta del
# theme, con el nombre que se les dio al generarlas con grub-mkfont.
